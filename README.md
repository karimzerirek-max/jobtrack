# JobTrack

JobTrack is a full stack job application tracker built to manage and organize job applications.

## Features

- Create job applications
- Edit existing applications
- Delete applications
- Update application status
- Filter applications by status
- Dashboard statistics
- Responsive interface
- Persistent data storage with SQLite
- REST API built with Express

## Tech Stack

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- SQLite

### Tools
- Git
- GitHub
- VS Code

## Application Status

Applications can be organized into:

- Applied
- Interview
- Offer
- Rejected

## API Endpoints

- `GET /api/jobs`
- `POST /api/jobs`
- `PUT /api/jobs/:id`
- `DELETE /api/jobs/:id`
